# LOK Digital 谜题 ASCII 格式规范

`parse.js` 是唯一的解析入口；`exportLevel` 输出严格格式，保证 round-trip 幂等
（`parse(export(x))` 与 `x` 等价，且 `export(parse(export(x))) === export(x)`）。

## 基本结构

```
<cols>
<rows>
<grid 行 1>
...
<grid 行 N>
```

- 前两行为整数：列数 `cols`、行数 `rows`
- 之后恰好 `rows` 行，每行 `cols` 个格子（不含洋葱 `*`）
- 若省略前两行（或前两行非整数），解析器会把整个输入当作裸网格，
  自动推断 `cols`（首行长度）与 `rows`（行数），要求各行等宽

## 格子符号

| 符号 | 含义 |
|---|---|
| `-` | 空格：不属于谜题，无瓦片，可被穿过 |
| `#` | 目标格：无字母，必须被涂黑（由单词的额外涂黑能力填充） |
| `=` | 预黑格：开局已涂黑 |
| `A`–`Z` | 字母格（含 `X` 导体、`?` 问号、`W` 云朵、`<>^v` 箭头） |
| `*` | 洋葱层符号：**紧跟在前一个格子之后，不占列**；连续 `*` 数量 = 洋葱层数（hp） |

### 洋葱 `*` 规则

`*` 不是独立格子。示例 `L**O*K**` 解析为 3 个格子：`L`（2 层）、`O`（1 层）、`K`（2 层）。
超过 `cols` 后剩余的 `*` 会被忽略（与游戏 `CoroutineSetup` 行为一致）。

### 特殊字母

- `X`：导体。拼词经过**不填黑**、不计入单词字母、可作折点转向、不可作首字母。
  最终需通过额外格/TA 全局/LOLO 对角线等方式填黑。
- `?`：问号。拼词时被赋予任意字母（每次经过可不同），指定为普通字母时**会被填黑**；
  在 `?` 处转向会被强制当作 `X`（不填黑）。
- `W`：云朵（世界 14）。`W` 词激活所有 W 格，并可将图案复制涂黑目标格。
- `<>^v`：箭头（世界 12）。点击箭头格把整条链沿箭头方向推动，箭头格自身填黑。

## 纪念碑格式（世界 13）

网格之后若出现 `&`，其后的内容为纪念碑拼块：

```
&
<拼块形状第 1 行>
<拼块形状第 2 行>
...
%
<x>/<y>      <- 拼块初始位置（x 列 / y 行，y 取负）
---
<下一个拼块形状>
%
<x>/<y>
```

- `&` 之后是第一个拼块，每个拼块以 `%` 结尾，后跟 `x/y` 坐标
- `---` 分隔下一个拼块
- 拼块内 `-` 为空、字母为格、`*` 为前一格的洋葱层数
- 网格中的 `#` 为槽位（`X` 为假槽位，仅装饰，不可落子）

## 解析错误契约

`parseLevel(text)` 返回 `{ ok:true, level }` 或 `{ ok:false, row, col, message }`。
失败时给出定位（行/列）与中文错误信息，绝不进入求解器。

常见错误：
- 空输入 / 全空白 → 「未输入内容」
- 非法字符 → 「第 X 行第 Y 列非法字符 'c'」
- 非等宽行 → 「第 X 行宽度 N 不足/超过 M」
- 网格超过 64×64 → 「网格超过上限 64×64」
- 独立 `*`（无前导字母）→ 「星号 * 必须紧跟字母格」
- 文件超过 64KB → 解析前以纯数值拒绝
