# LOK Digital 求解器

纯静态网页版 **LOK Digital** 谜题求解器 —— 内置全部 151 个官方关卡，支持自动求解、文字步骤、逐步动画回放、ASCII 谜题导入，以及可视化画题工具。

## 在线访问

GitHub Pages 托管：**https://betaller.github.io/lok-digital-solver/**

## 功能

- 🎮 **关卡库**：内置 14 个世界全部 151 个官方关卡，按世界分组浏览
- 🧩 **自动求解**：自由词库推导（不依赖提示词），支持全部关键词机制（LOK/TLAK/TA/BE/LOLO/ABA/GRIVA/W/X/?/洋葱层）
- 🎬 **动画回放**：分步涂黑动画 + 文字步骤说明，支持 播放/暂停/上一步/下一步/速度调节
- 📥 **ASCII 导入**：粘贴或上传 `.txt` 谜题文件即可求解
- ✏️ **画题工具**：可视化绘制谜题（支持空格/字母+洋葱层/目标格/预黑格/导体X/问号/云朵/箭头），导出 ASCII 再求解
- 🐦 **OLKO 探测**：检测每个关卡能否拼出隐藏词 OLKO，并给出拼法

## 快速启动

项目是纯静态网站，无构建步骤、无运行时依赖：

```bash
# 方式一：直接访问 GitHub Pages 在线地址
# 方式二：本地起一个静态服务器
npx serve .
# 或
python -m http.server 8080
```

然后浏览器打开 `http://localhost:8080`。

> 注意：由于浏览器安全策略，直接双击 `index.html`（`file://` 协议）无法加载 ES Module，请使用上面的静态服务器方式，或直接访问在线地址。

## 求解器说明

- **词库**：固定全局关键词表（含反向拼写），每步用当前盘面可拼字母查表（自由推导）
- **终止条件**：所有非空格子全部涂黑（与游戏 `CheckWin` 一致）
- **路径枚举**：支持 X 导体转向、? 通配（多次经过可赋不同字母）、跨已黑格/空位跳跃、LOLO 环绕
- **结果语义**：`已找到解` / `未在时限内找到`（超时，可加大预算重试） / `确认无解`（穷尽搜索）
- 世界 13 纪念碑采用两阶段求解（拼块放置 + 拼词），支持 Looped ? 通配符回路
- 世界 12 箭头为 BFS 推箱式搜索

## 已知限制

- 箭头关卡 (世界 12)：BFS 最多搜索 25 步 ~5M 状态，部分长解 (>25 推) 的关卡无法在限制内找到
- 纪念碑 (世界 13)：13-6 所有拼块均无导体 X/?，直线上无完整关键词可拼，需进一步排查机制
- ? 回路关卡 (世界 8)：? 消耗 vs 保持通配符的边界行为需精确对齐游戏原版
- 部分高难关卡求解较慢 (~30s)，UI 预算已对齐测试 (12s/4M 节点)

## 隐私

本网站为纯静态页面：**所有谜题处理（粘贴/上传/求解/画题）均在浏览器本地完成，不上传任何服务器**。页面无 cookie、无追踪、无外部请求。
